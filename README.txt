# Поиск подозрительных транзакций

Учебный проект по антифроду: анализ покупок и переводов, поиск аномалий и построение рейтинга подозрительных операций.

## Данные

В выборке 199 768 транзакций:

- 1 500 операций с подтвержденным фродом;
- 198 268 операций с неизвестной меткой.

Отсутствие подтверждения не означает, что операция легитимна.

## Что сделано

- Исследована связь подтвержденного фрода с суммой, временем, страной IP, каналом и категорией магазина.
- Добавлены признаки поведения клиента: медиана предыдущих сумм, новое устройство, новый получатель и частые операции.
- Найдены аномалии без использования меток: резкие превышения привычной суммы и плотные серии операций.
- Построен рейтинг подозрительности с помощью PU-bagging на XGBoost.

Каждая модель PU-bagging обучается на подтвержденных случаях и случайной подвыборке неизвестных операций. Оценки моделей усредняются.

## Проверка результата

Параметры подбираются на ранних операциях с кросс-валидацией по времени. Проверка проводится на операциях с 22 октября.

Основная метрика - доля известных подтверждений, попавших в верхние 1%, 5% и 10% рейтинга.

Для итогового рейтинга используются OOF-оценки: каждая операция оценивается ансамблем, который на ней не обучался.

## Результат

В ноутбуке доступны:

- ITOG - оценки всех транзакций;
- unknown_ranking - рейтинг только операций с неизвестной меткой.

Более высокий балл означает более высокий приоритет проверки. Балл не является достоверной вероятностью фрода. Из-за частичной разметки качество на скрытых мошеннических операциях и число ложных срабатываний неизвестны.

## Стек

Python, pandas, NumPy, Matplotlib, scikit-learn, XGBoost.
